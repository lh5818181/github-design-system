# GitHub Design System

Bem-vindo ao Design System do GitHub, um projeto criado para demonstrar a aplicação dos conceitos de **Design System** e **Atomic Design** em um ambiente de desenvolvimento moderno com **React** e **Storybook**, conforme detalhado no **Capítulo 15 do ebook "Design para Devs"**.

## Objetivo

O objetivo deste Design System é fornecer um conjunto de componentes reutilizáveis e documentados que garantam a **consistência** e a **eficiência** no desenvolvimento de interfaces.

## Estrutura

A estrutura do projeto segue o padrão de Atomic Design:

*   **Atoms**: Elementos básicos (ex: Botão, Ícone).
*   **Molecules**: Agrupamento de Atoms (ex: Campo de Busca).
*   **Organisms**: Agrupamento de Molecules e Atoms (ex: Cabeçalho).
*   **Templates**: Estruturas de página (ex: Layout de Repositório).
*   **Pages**: Páginas completas que utilizam os Templates.

## Como Usar

Para começar, navegue pelos componentes na barra lateral para ver a documentação, exemplos de uso e propriedades de cada elemento.

**Divirta-se construindo interfaces consistentes!**
