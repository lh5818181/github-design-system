# GITHUB DESIGN SYSTEM 🐙
### Um Sistema de Design Modular e Inspirado no Padrão GitHub

👋 **Bem-vindo ao nosso ecossistema de componentes.**

Este sistema foi construído para garantir que o desenvolvimento de interfaces siga o padrão de qualidade do GitHub, focando em **acessibilidade**, **performance** e **modularidade**.

---

### 🎯 Atomic Design na Prática
Nossa estrutura é fundamentada na modularidade, permitindo que cada peça seja testada individualmente e reutilizada com total segurança.

#### 🧱 Átomos
*Elementos base e indivisíveis da interface.*
> `Button` • `Text` • `Icon` • `Link`

#### 🧬 Moléculas
*Grupos de átomos que formam componentes funcionais simples.*
> `Pagination` • `Dropdown` • `Tabs` • `IssueLabel`

#### 🏗️ Organismos
*Seções complexas formadas pela união de moléculas e átomos.*
> `IssueListItem` • `IssueList`
