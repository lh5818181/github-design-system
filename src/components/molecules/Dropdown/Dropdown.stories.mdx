# ⬇️ Dropdown (Menu de Contexto)

O componente `Dropdown` é uma Molécula utilizada para exibir menus de contexto, listas de ações ou filtros que não devem ocupar espaço permanente na tela.

Ele é implementado com lógica de **fechamento ao clicar fora** (`click-outside`) e focado em alta acessibilidade.

***

## 🚀 Exemplo de Uso: Menu de Ações à Direita

<Canvas>
  {() => {
    return (
        <div style={{ display: 'flex', justifyContent: 'flex-end', padding: '10px 0' }}>
            <Dropdown 
                trigger={<Button variant="secondary">Configurações</Button>}
                align="right"
                ariaLabel="Menu de configurações do usuário"
            >
                <DropdownItem onClick={() => console.log('Opção 1')}>
                    Editar Perfil
                </DropdownItem>
                <DropdownItem onClick={() => console.log('Opção 2')}>
                    Mudar Tema
                </DropdownItem>
                <DropdownItem onClick={() => console.log('Opção 3')}>
                    Sair
                </DropdownItem>
            </Dropdown>
        </div>
    );
  }}
</Canvas>

### `DropdownItem`

Este componente interno herda todas as propriedades nativas de um `<button>` (incluindo `onClick`, `disabled`, etc.). Possui `role="menuitem"` para acessibilidade.

***

## ♿️ Acessibilidade (A11Y)

O `Dropdown` segue rigorosamente o padrão WAI-ARIA para menus pop-up:

1.  **Semântica:** O menu utiliza `role="menu"` e os itens internos utilizam `role="menuitem"`.
2.  **Estado:** O botão de acionamento (`trigger`) usa `aria-expanded` para indicar se o menu está aberto ou fechado.
3.  **Foco:** O menu fecha automaticamente ao pressionar **ESC** e ao clicar fora (`click-outside`).
