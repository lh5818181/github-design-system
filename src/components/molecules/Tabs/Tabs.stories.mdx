# 📁 Tabs (Abas de Navegação)

O componente `Tabs` (Abas) é uma Molécula essencial para a navegação primária em páginas com múltiplas visualizações ou contextos (ex: "Código", "Issues", "Pull Requests" no GitHub).

Ele implementa o padrão de acessibilidade **WAI-ARIA Tabs** para garantir a usabilidade por teclado e leitores de tela.

***

## 🚀 Exemplo de Uso

Este exemplo demonstra as classes ativas e a contagem opcional.

<Canvas>
  {() => {
    const defaultTabs = [
        { id: 'code', label: 'Code' },
        { id: 'issues', label: 'Issues', count: 12 },
        { id: 'prs', label: 'Pull Requests', count: 5 },
        { id: 'actions', label: 'Actions' },
    ];
    
    // Wrapper para simular o estado ativo
    const [activeTab, setActiveTab] = React.useState('issues');

    const contentMap = {
        'code': <Text size="medium" variant="muted">Conteúdo da Aba Code.</Text>,
        'issues': <Text size="medium">Conteúdo da Aba Issues (Principal).</Text>,
        'prs': <Text size="medium" variant="muted">Conteúdo da Aba Pull Requests.</Text>,
        'actions': <Text size="medium" variant="muted">Conteúdo da Aba Actions.</Text>,
    };

    return (
        <div style={{ paddingBottom: '16px' }}>
            <Tabs 
                tabs={defaultTabs} 
                initialTabId={activeTab} 
                onTabChange={setActiveTab} 
            />
            <div style={{ padding: '16px', border: '1px solid var(--color-border-default)', borderTop: 'none', borderRadius: '0 0 6px 6px' }}>
                {contentMap[activeTab]}
            </div>
        </div>
    );
  }}
</Canvas>

## ⚙️ Propriedades (`TabsProps`)

A tabela a seguir lista todas as propriedades disponíveis para customização e controle do componente `Tabs`.

<ArgTypes of={Tabs} />

### `TabItem` (Interface)

| Propriedade | Tipo | Descrição |
| :--- | :--- | :--- |
| `id` | `string` | **Obrigatório**. Identificador único da aba, usado para controle de estado. |
| `label` | `string` | **Obrigatório**. O texto principal visível da aba. |
| `count` | `number` | Opcional. Um número de notificação ou contagem (ex: número de Issues abertas). |

***

## ♿️ Acessibilidade (A11Y)

O `Tabs` é construído com foco total na acessibilidade, seguindo as diretrizes **WAI-ARIA Tabs**:

1.  **Estrutura Semântica:** O contêiner de abas possui `role="tablist"` e cada botão individual possui `role="tab"`.
2.  **Estado Ativo:** A aba selecionada é comunicada via `aria-selected=true`.
3.  **Associação de Painel:** Cada aba possui um `aria-controls` que deve apontar para o `id` do painel de conteúdo correspondente (ex: `panel-issues`), estabelecendo a relação de conteúdo.
